How the Tool-Use Loop Works

What makes these agents — not pipeline steps

// Each agent function runs this loop
let iterations = 0
let messages = [{ role: "user", content: task_prompt }]

while (iterations < 2) {
const response = await anthropic.messages.create({
model, system_prompt, tools, messages
})

// Agent chose to stop — satisfied with its work
if (response.stop_reason === "end_turn") break

// Agent called tools — execute them, feed results back
const tool_results = await executeTools(response.content)
messages.push(
{ role: "assistant", content: response.content },
{ role: "user", content: tool_results }
)
iterations++
}

What this enables

Analyst — Draft Mode
Pass 1: Calls query_inventory + query_sales. Reasons over data. Calls submit_section for each of the 5 sections.

Pass 2: Calls read_my_sections + read_past_challenges. Reviews what it wrote. If it finds a gap — revises. Calls submit_section again to overwrite. Then stops.
Auditor — Review Mode
Pass 1: Calls read_analyst_sections + query_inventory + query_sales. Cross-references claims against data. Calls submit_challenge or approve_section per section.

Pass 2: Calls read_analyst_sections again to check for anything missed. If satisfied — stops. If not — revises challenges.

The key difference from the current pipeline

In the current design, the orchestrator decides what data to send and when to stop. In this design, the agent decides — it chooses which tools to call, in what order, and signals done by returning without tool calls. The orchestrator just enforces the 2-pass ceiling.
